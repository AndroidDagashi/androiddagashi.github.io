ユーザーへの質問や確認が必要な場合は、テキストで質問を書くのではなく、必ず AskUserQuestion ツールを使用すること。

AskUserQuestion を呼ぶ同一ターン内でツール呼び出しの前に書いたテキストは、ユーザーに表示されないことがある（実測で確認済み。既知バグ: https://github.com/anthropics/claude-code/issues/75182 ）。そのため:

- 質問文（question）と選択肢（options の label / description）だけで判断できる自己完結な内容にすること。直前のテキストで説明した前提に依存しない。
- ユーザーが読むべき長い説明・サマリ・回答は、ツール呼び出しを後続させずにターン末尾のテキストとして出す。その場合の確認はユーザーの次の反応を待ってから行う。
